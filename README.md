# Nova Tab – Student Dashboard & Search (v2)

Install / update: chrome://extensions → Developer mode → Load unpacked (select this folder).
Updating from v1? Copy these files over your old folder, then press the reload button on the extension card — your saved shortcuts stay.

Features: multi-engine & AI search · ⚡ Compare mode (one question → many AIs) · quick commands (yt, gh, so, wiki, maps, tr, npm, mdn…)
· Prompt library (✨) · saved sites with categories + drag & drop · Bangladesh time (12/24h) · Pomodoro + daily goal + streak
· Assignments · Exam countdown · Weekly class routine · CGPA calculator · Quick notes · Weather · Prayer times
· Focus Mode (site blocker) · Tab sessions · Light/dark, 6 colour themes, custom/daily wallpaper · Backup & restore
