## Telegram summaries
Open the Telegram button or Settings → AI & tools → Telegram study summaries. Create a bot with [@BotFather](https://t.me/BotFather), save its token, send `/start` to the bot, then select **Find chat ID**. Select the categories to include, then use **Push today’s summary** to send a report immediately. The same checked categories apply to manual and automatic reports; unchecked categories are excluded. Enable the 24-hour schedule to repeat the selected-category report every 24 hours until disabled. The bot must be able to message your chat.

Telegram credentials are stored in local extension storage only; they are not included in exported backups or Chrome Sync. Quick Notes text is sent only when that category is selected. Telegram delivery requires an internet connection and the browser to be running.
